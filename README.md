# MachineLearningProject

# Problem
Continuous Glucose Monitoring (CGM) devices generate thousands of data points, but current software only provides raw graphs, forcing clinicians and patients to manually identify trends that is an unrealistic task that risks missing critical glucose patterns

The goal of this project was to develop a **proof-of-concept prototype** that demonstrates how **automated data analysis and machine learning methods** can extract meaningful and actionable insights from **Continuous Glucose Monitoring (CGM)** data.

##  Modeling Approach

We explored and compared several complementary analytical and machine learning techniques:

- **Clustering**  (Merilin, Merette)
- **Anomaly Detection/Visualisations on aggregated data**  (Merilin, Merette)
- **XGBoost (Gradient Boosting Trees)**  (Hendrik)
- **Time-Series Models**  (Merilin)
- **Rule-Based Model**  (Hendrik)


  
Clustering and visualisations on aggregated data proved to be most useful. The most useful experiments are separately brought out in the folder "Final".
